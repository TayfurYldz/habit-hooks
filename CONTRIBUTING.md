# Contributing

Good places to start:

- Issues labelled [`good first issue`](https://github.com/habit-hooks/habit-hooks/labels/good%20first%20issue)
- If you want to donate agent time rather than your own, look for
  [`ready for unsupervised`](https://github.com/habit-hooks/habit-hooks/labels/ready%20for%20unsupervised)
  — see [AI agents](#ai-agents) below.

## Community

A Discord community exists for discussion and planning. There is no public invite — 
reach out to [Ivett Ördög](https://ivettordog.com/) directly

## Before you open a PR

1. Comment on the issue you would like to work on.
2. Wait until the issue is assigned to you.
3. Only then open the PR. **PRs opened before their issue was assigned to their author are
   automatically closed.**

## AI agents

Using an AI agent to write your PR is welcome — with one condition: **a human must review the code.
Unreviewed PRs will be rejected.** 

The exception is [`ready for unsupervised`](https://github.com/habit-hooks/habit-hooks/labels/ready%20for%20unsupervised)
issues, for contributors donating agent time but not their own. These are exempt from the human-review
requirement — but the assignment rule still applies: the issue must be assigned to you before you open
the PR.
